# DevDocify docs

DevDocify is a multi-docset documentation platform built on Docusaurus. It includes a CLI, Algolia search, an AI assistant panel, interactive API playgrounds, and CI quality gates. You can deploy the whole system to Vercel in minutes.

    documentation with confidence.
  </p>
</div>

## What's included

<div className="docs-card-grid">
  <div className="docs-card">
    <h3>Multi-docset navigation</h3>
    <p>Each product gets its own docset under a dedicated base path, with isolated sidebars and navigation contracts.</p>
  </div>
  <div className="docs-card">
    <h3>Docify CLI</h3>
    <p>A command-line tool for local dev, content validation, broken-link checks, SEO scoring, and project scaffolding.</p>
  </div>
  <div className="docs-card">
    <h3>Algolia search</h3>
    <p>Contextual search across all docsets, with structured records for docs and API operations pushed to Algolia on deploy.</p>
  </div>
  <div className="docs-card">
    <h3>AI assistant panel</h3>
    <p>An inline assistant panel that answers questions about the current docset with grounded retrieval and quality validation in CI.</p>
  </div>
  <div className="docs-card">
    <h3>API playgrounds</h3>
    <p>Interactive OpenAPI explorers embedded in product docsets, with pre-filled defaults for fast onboarding.</p>
  </div>
  <div className="docs-card">
    <h3>Enterprise controls</h3>
    <p>SAML configuration, RBAC publish checks, and typed analytics events for protected documentation workflows.</p>
  </div>
  <div className="docs-card">
    <h3>Diagram support</h3>
    <p>Mermaid and PlantUML diagrams render inside docs so architecture pages can stay close to implementation detail.</p>
  </div>
  <div className="docs-card">
    <h3>Quality gates</h3>
    <p>Type checks, content linting, assistant policy validation, Lighthouse CI, and playground health checks run before release.</p>
  </div>
</div>
